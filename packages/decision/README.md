# Decision Package

Reglas auxiliares de riesgo, restricciones de cartera y traduccion de acciones a decisiones simuladas.

El diseno anterior de perfiles de riesgo, votos y consenso queda como antecedente. En el camino MARL actual, este paquete debe alimentar al simulador, al agente Portfolio y a la capa de evaluacion.

Los agentes que consumen estas reglas estan en [../../docs/agent-protocols.md](../../docs/agent-protocols.md).
