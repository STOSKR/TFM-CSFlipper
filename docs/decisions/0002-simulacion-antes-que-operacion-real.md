# ADR 0002: Simulación Antes que Operación Real

## Estado

Aceptada.

## Contexto

El proyecto trata con activos digitales que pueden tener valor económico. El objetivo académico es validar estrategias y arquitectura, no ejecutar operaciones reales.

## Decisión

Todas las decisiones serán simuladas hasta que el Scrum Master solicite explícitamente otra fase.

## Consecuencias

- Menor riesgo financiero.
- Mejor trazabilidad para el TFM.
- Permite evaluar contra histórico y datos no vistos.
